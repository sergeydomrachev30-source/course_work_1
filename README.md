Приложение на Python для автоматизированного анализа личных финансов. Программа обрабатывает банковские выписки в формате Excel (`.xlsx`), рассчитывает кэшбэк, анализирует траты по категориям и дням недели, отслеживает курсы валют и сохраняет отчеты в формате JSON.

Содержание

-   Функционал
-   Система отчетов (Reports)
-   Умный поиск и Инвесткопилка
-   Технологии и декораторы
-   Требования к данным (Excel)
-   Инструкция по запуску

----------

Функционал

1. Главная страница (`main_page_function`)

Имитирует выдачу данных для мобильного приложения:

-   **Приветствие**: Динамическое (зависит от времени суток).
-   **Карты**: Сводка по каждой карте (последние 4 цифры, общие траты, кэшбэк 1%).
-   **Топ-5 транзакций**: Самые крупные списания.
-   **Рынок**: Актуальные курсы валют и котировки акций S&P 500.

2. Страница событий (`events_page_function`)

Детальный отчет за выбранный период:

-   **Периоды**: Неделя (**W**), Месяц (**M**), Год (**Y**) или все время (**ALL**).
-   **Группировка**: Расходы, доходы и переводы разделены по категориям.

----------

Система отчетов (Reports)

Специализированный модуль для анализа трат за  **последние 90 дней**  от указанной даты.

-   **`spending_by_category`**: Траты в конкретной категории (например, «Супермаркеты»). Поиск  **регистронезависимый**.
-   **`spending_by_weekday`**: Средние траты по дням недели. Индексация от  **1 (Пн)**  до  **7 (Вс)**.
-   **`spending_by_workday`**: Сравнение среднего чека в рабочие и выходные дни.

----------

Умный поиск и Инвесткопилка

Инструменты интеллектуальной обработки текста с помощью  **RegEx**:

1.  **Инвесткопилка (`investment_bank`)**: Рассчитывает сумму накоплений путем округления трат до шага  **10, 50 или 100 руб.**
2.  **Поиск по тексту (`search_transactions`)**: Поиск слова в описании или категории транзакции.
3.  **Поиск телефонов (`find_phone_transactions`)**: Находит транзакции с мобильными номерами РФ в описании.
4.  **Переводы физлицам (`find_person_transfers`)**: Фильтрует переводы по паттерну «Имя И.» (например,  _Валерий А._).

----------

Технологии и декораторы

Декоратор  `@report_to_file`

Автоматизирует сохранение результатов функций в JSON-файлы:

-   Сохраняет файл с именем  `название_функции.json`.
-   Поддерживает кастомные имена файлов:  `@report_to_file("my_report.json")`.
-   Не создает пустые файлы, если данных за период не нашлось.

**Стек:**  `Python 3.10+`,  `Pandas`  (анализ данных),  `RegEx`  (поиск паттернов),  `Pytest`  (тестирование),  `Logging`  (отслеживание ошибок).

Единая точка входа (`main.py`)

Модуль  `main.py`  объединяет возможности  **Views**,  **Reports**  и  **Services**  в один автоматизированный процесс.

Логика работы Main:

При запуске программа выполняет последовательный цикл анализа:

1.  **Загрузка данных**: Считывает транзакции из  `data/operations.xlsx`. Если файл пуст или поврежден, выполнение безопасно прерывается с записью в лог.
2.  **Генерация интерфейсов (Views)**:
    -   Формирует данные для "Главной" и "Событий" на заданную дату.
    -   Автоматически определяет время суток для корректного приветствия.
3.  **Запуск аналитических отчетов (Reports)**:
    -   Вызывает функции анализа по категориям и дням недели.
    -   Благодаря декоратору  `@report_to_file`, результаты этих функций  **автоматически сохраняются**  в отдельные JSON-файлы в корне проекта.
4.  **Работа сервисов (Services)**:
    -   Рассчитывает сумму накоплений в  **Инвесткопилку**  (с учетом выбранного лимита округления).
    -   Выполняет поиск переводов по мобильным номерам и именам физлиц с помощью регулярных выражений.
5.  **Финальный свод**:
    -   Собирает ключевые метрики (приветствие, курсы валют, сумму накоплений) в единый итоговый файл  `full_project_analysis.json`.

2. Настройка API

Для работы курсов валют добавьте ваш ключ в  `src/config.py`:

python
```
api_key = "ВАШ_КЛЮЧ"

```
3. Запуск и тесты

-   Поместите выписку в  `data/operations.xlsx`.
-   Запустите приложение:  `python main.py`.
-   Запустите тесты:  `pytest`.
